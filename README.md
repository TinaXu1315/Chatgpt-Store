## Cloud Environment

This repository includes a [Development Container](https://containers.dev/)
configuration in `.devcontainer/devcontainer.json`. Cloud development services
that support the Development Container specification can use it to create a
consistent Ubuntu 24.04 environment for the repository.

To start it from VS Code, install the **Dev Containers** extension, open the
repository, and run **Dev Containers: Reopen in Container** from the command
palette. On a compatible cloud service, create a new environment from this
repository; the service will discover the configuration automatically.
